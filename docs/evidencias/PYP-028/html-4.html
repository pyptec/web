Capacidades técnicas

Del circuito electrónico a la operación industrial

Combinamos hardware embebido, comunicaciones industriales, software y supervisión para resolver necesidades concretas en planta.

Hardware electrónico propio

Diseño e integración de tarjetas de interfaz para entradas digitales, salidas de relé, señales analógicas y comunicaciones industriales, según los requerimientos de cada proyecto.

Control Edge

Adquisición, reglas operativas, temporización y procesamiento local sobre equipos embebidos, sin depender de la nube para las funciones críticas.

Interfaces industriales

Integración mediante RS-485, Modbus RTU/TCP, RS-232, señales discretas y entradas analógicas, con acondicionamiento adecuado para cada instalación.

CAN y J1939

Lectura pasiva de mensajes CAN de 29 bits y decodificación de variables identificadas en controladores de grupos electrógenos, con monitoreo y diagnóstico.

Operación local y resiliencia

Servicios supervisados, watchdog, reloj de tiempo real y almacenamiento temporal para continuar registrando eventos ante fallas de conectividad.

Integración de información

Dashboards locales, históricos, APIs y publicación MQTT para enlazar los datos de campo con plataformas empresariales o servicios en la nube.

Desarrollo propio

Gateways y tarjetas electrónicas para campo

Las plataformas SAMEE incorporan interfaces y funciones adaptadas a la adquisición y supervisión de variables industriales.

Hardware de interfaz

Desarrollos con entradas digitales, relés, entradas analógicas, RS-485, RS-232, RTC y watchdog externo. La configuración de interfaces depende de la versión de hardware y del proyecto.

Integración de generadores

Monitoreo CAN / SAE J1939

Desarrollo de adquisición y diagnóstico para grupos electrógenos mediante lectura de tramas CAN y visualización de variables identificadas en el controlador.

Qué permite la integración

Variables eléctricas

Frecuencia, tensiones y batería cuando están disponibles en los mensajes identificados.

Estados y eventos

Supervisión de condiciones operativas y eventos relevantes del controlador.

Recepción CAN

Interfaz CAN de 250 kbps y mensajes extendidos de 29 bits en el entorno de desarrollo.

Adquisición pasiva

Lectura sin transmitir comandos al bus durante las pruebas de monitoreo.

Caso de desarrollo

Controlador de grupo electrógeno

Pruebas de integración con Raspberry Pi, interfaz CAN y software de supervisión local. Se han identificado y decodificado señales de frecuencia, tensiones y batería, con visualización mediante dashboard.

La compatibilidad de señales y funciones se valida para cada modelo de controlador. No se presenta como una solución de control remoto certificada.
