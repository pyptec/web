# PYP-016 — Actualización controlada de React Router

Proyecto: D:\promate\web\pyp-web

## OBJETIVO

Actualizar React Router DOM desde la versión 6.30.6 hasta la versión 7.18.4, junto con React Router compatible, para corregir las vulnerabilidades de producción identificadas en PYP-015.

Preservar la navegación, el diseño, el formulario Netlify y el SEO.

1. Leer AGENTS.md.
2. Revisar docs/evidencias/PYP-015/resultado.md.
3. Revisar la bitácora.
4. Ejecutar git status --short.
5. Inspeccionar package.json, package-lock.json y las importaciones de React Router.
6. Verificar la versión instalada de Node.js y su compatibilidad con React Router 7.18.4.
7. Confirmar que la versión objetivo existe y que las vulnerabilidades identificadas están corregidas.

Antes de instalar, registrar el estado inicial.

No continuar si el entorno no cumple los requisitos de compatibilidad.

## FASE 2 — ACTUALIZACIÓN

Actualizar exclusivamente:

- react-router-dom a 7.18.4.
- react-router a 7.18.4, cuando corresponda.

Permitir los cambios transitivos estrictamente necesarios para resolver estas dependencias.
