No modificar el diseño, contenido comercial, navegación ni formulario Netlify.

4. Ejecutar git status --short.

- Open Graph title.

- Open Graph URL.
- Open Graph image válida, si existe un recurso adecuado.
- Twitter Card coherente, si ya está implementada.

Usar exclusivamente información comercial existente y verificable del proyecto.

No inventar certificaciones, clientes, cifras ni funcionalidades.

[https://pyptecnologia.com](https://pyptecnologia.com)

## FASE 3 — HTML INICIAL

Antes de modificarlo:

1. Analizar el comportamiento actual de scripts/generar-seo.mjs.
2. Revisar cómo Netlify entrega las rutas SPA.
3. Determinar si se requieren archivos HTML por ruta, prerenderizado o ajustes al proceso existente.
4. Elegir la alternativa de menor complejidad compatible con Vite y Netlify.
5. Evitar soluciones que funcionen únicamente después de ejecutar JavaScript.

No romper la navegación React Router.

No introducir dependencias nuevas sin justificarlo y solicitar autorización.

- Coherencia entre canonical y sitemap.

No inventar fechas de última modificación.
