# PYP-006 — Corrección y unificación funcional de la navegación corporativa

Proyecto: D:\promate\web\pyp-web

## PROBLEMA DETECTADO

El usuario verificó visualmente que Automatización/Edge muestra una barra con varios enlaces, mientras Monitoreo Energético e IoT Industrial siguen mostrando prácticamente la navegación antigua.

Aunque las tres páginas utilizan Navbar.jsx, no existe todavía una navegación corporativa común.

Por tanto, PYP-004 fue técnicamente implementado, pero la unificación funcional está incompleta.

## OBJETIVO

Implementar una navegación corporativa compartida para las tres páginas interiores, con acceso a todas las soluciones existentes y conservando los enlaces de contacto.

## FASE 1 — AUDITORÍA

1. Lee AGENTS.md.
2. Ejecuta git status --short.
3. Inspecciona Navbar.jsx y las tres páginas interiores.
4. Inspecciona las rutas existentes en main.jsx.
5. Comprueba los destinos reales de Proyectos, Tecnología, Plataforma y Contacto.
6. Conserva los cambios anteriores.

## FASE 2 — NAVEGACIÓN CORPORATIVA

Implementa esta navegación común:

- Inicio → /
- Soluciones → menú desplegable:
  - Monitoreo Energético → /monitoreo-energetico
  - IoT Industrial y LoRaWAN → /iot-industrial
  - Automatización y Edge → /automatizacion-edge
- Proyectos → /#proyectos, si existe esa sección
- Tecnología → /#tecnologia, si existe esa sección
- Plataforma → [https://iotrack.com.co](https://iotrack.com.co)
- Hablemos → /#contacto, si existe esa sección

No crees enlaces a páginas que todavía no existen.

Mantén Producción y OEE, y Agua y Vertimientos como proyectos futuros documentados, pero no como enlaces activos.

## FASE 3 — DISEÑO Y ACCESIBILIDAD

- Reutiliza Navbar.jsx.
- Conserva el logo oficial y la paleta corporativa.
- Implementa el menú Soluciones para escritorio y móvil.
- Asegura que el menú pueda abrirse mediante clic y teclado.
- Usa atributos de accesibilidad apropiados.
- Identifica visualmente la solución activa.
- Evita que la barra desborde en pantallas pequeñas.
- Conserva un botón Hablemos visible y funcional.
- Si es necesario, permite enlaces secundarios locales específicos por página, sin duplicar encabezados.

No modifiques contenidos técnicos, imágenes, formularios, textos comerciales, SEO ni rutas.

No modifiques todavía App.jsx.

No instales dependencias adicionales.
