# PYP-007 — Navegación local de las páginas interiores

Proyecto: D:\promate\web\pyp-web

## OBJETIVO

Mejorar la experiencia de navegación de las páginas interiores de PYP mediante dos niveles claramente diferenciados:

1. Navegación corporativa compartida para cambiar entre páginas.
2. Navegación local compacta para desplazarse rápidamente entre las secciones de la página actual.

La referencia funcional es la página Automatización y Edge Computing, que ya dispone de enlaces locales.

## FASE 1 — AUDITORÍA

1. Lee AGENTS.md.
2. Ejecuta git status --short.
3. Inspecciona Navbar.jsx y las páginas MonitoreoEnergetico.jsx, IoTIndustrialLoRaWAN.jsx y AutomatizacionEdge.jsx.
4. Identifica los ID reales de las secciones de cada página.
5. Identifica la implementación actual de la navegación secundaria de Edge.
6. No inventes anclas ni secciones que no existan.

## FASE 2 — IMPLEMENTACIÓN

Implementa una navegación local reutilizable, preferiblemente mediante un componente independiente `src/components/SectionNav.jsx`, salvo que el análisis del código justifique otra solución más sencilla.

Mantén Navbar.jsx como navegación corporativa.

En las tres páginas interiores:

- Conserva Inicio, Soluciones, Proyectos, Tecnología, Plataforma y Hablemos en la barra corporativa.
- Añade navegación local utilizando exclusivamente secciones existentes.
- Conserva las anclas y contenidos actuales.
- Evita enlaces duplicados innecesarios.
- Mantén el diseño corporativo aprobado.
- No añadas una segunda barra corporativa.

La navegación local debe ser compacta y visualmente subordinada a la principal.

## FASE 3 — EXPERIENCIA DE USUARIO

En escritorio:

- Mostrar los enlaces locales horizontalmente.
- Distinguir visualmente la navegación local.
- Permitir acceso rápido a las secciones técnicas.

En móvil:

- Permitir desplazamiento horizontal de los enlaces locales cuando sea necesario.
- Evitar que los enlaces queden cortados o inaccesibles.
- No crear una barra de varias filas que ocupe demasiado espacio.

En todas las pantallas:

- Mantener el encabezado principal accesible.
- Evitar que el desplazamiento a un ancla oculte el título bajo el encabezado.
- Conservar navegación por teclado y foco visible.
- Respetar la preferencia de movimiento reducido.
- Evitar saltos o desplazamientos incorrectos al cambiar de página.

Si se implementa resaltado de sección activa, debe reflejar la sección visible y no solamente el último enlace seleccionado.
