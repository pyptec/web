# PYP-008 — Integración de navegación en la página principal

Proyecto: D:\promate\web\pyp-web

## OBJETIVO

Integrar la navegación corporativa compartida en la página principal de PYP Tecnología Electrónica SAS, manteniendo la experiencia de navegación aprobada en las páginas interiores.

Registrar también la validación del usuario de PYP-007.

## FASE 1 — AUDITORÍA

1. Lee AGENTS.md.
2. Ejecuta git status --short.
3. Inspecciona src/App.jsx, src/components/Navbar.jsx, src/components/SectionNav.jsx y src/utils/scrollToSection.js.
4. Identifica los enlaces, anclas, estados y mecanismos de desplazamiento existentes en App.jsx.
5. Verifica los destinos reales antes de realizar modificaciones.
6. Conserva todos los cambios previos.

## FASE 2 — REGISTRO DE VALIDACIÓN

Actualiza docs/BITACORA_DESARROLLO.md.

Añade a PYP-007 una nota de validación posterior:

"El usuario confirmó que las tres páginas interiores muestran correctamente las barras y que la navegación funciona."

No atribuyas al usuario pruebas específicas que no haya declarado.

## FASE 3 — IMPLEMENTACIÓN

Sustituye únicamente el encabezado corporativo de App.jsx por Navbar.jsx.

Conserva:

- Logo oficial.
- Inicio.
- Soluciones desplegable.
- Proyectos.
- Tecnología.
- Plataforma.
- Hablemos.
- Formulario Netlify.
- Contenido comercial.
- Imágenes.
- Secciones existentes.
- Rutas y SEO.

No dupliques encabezados.

Analiza el mecanismo de scroll existente y evita conflictos con la nueva navegación.

Si las secciones de la página principal justifican una navegación local, utiliza SectionNav.jsx con los ID existentes. Mantén la segunda fila compacta y evita duplicar opciones de la barra corporativa.

No añadas enlaces a páginas inexistentes.

## FASE 4 — RESTRICCIONES

No modificar main.jsx, Seo.jsx, dependencias ni archivos generados.

No instalar paquetes.

No cambiar contenidos comerciales.

No realizar commits, push ni despliegues.

## FASE 5 — DOCUMENTACIÓN

Guarda este prompt completo en:

docs/prompts/PYP-008.md

## FASE 6 — VALIDACIÓN

1. Verifica que la página principal tenga una sola Navbar.
2. Comprueba Inicio, Soluciones, Proyectos, Tecnología, Plataforma y Hablemos.
3. Comprueba navegación hacia las tres páginas interiores.
4. Verifica las anclas locales y el desplazamiento.
5. Comprueba que el formulario Netlify permanezca intacto.
6. Realiza pruebas en escritorio y móvil si hay navegador disponible.
7. Ejecuta compilación comercial temporal sin alterar dist.
8. Ejecuta compilación VitePress.
9. Comprueba git diff --check sobre los archivos modificados.
10. Revisa git status --short.
