# PYP-030 — Corrección de datos estructurados de CLG

Continuar en el proyecto:

D:\promate\web\pyp-web

## Contexto

Google Search Console ha confirmado que la página:

[https://pyptecnologia.com/proyectos/clg/](https://pyptecnologia.com/proyectos/clg/)

se puede indexar y ya tiene una solicitud de indexación enviada.

Sin embargo, Google detectó un problema crítico en los fragmentos de productos:

"Debe especificarse offers, review o aggregateRating".

El elemento identificado es:

- Tipo: Product
- Nombre: CLG — Cliente Ganador
- ID: [https://pyptecnologia.com/proyectos/clg/#producto](https://pyptecnologia.com/proyectos/clg/#producto)

CLG se comercializa mediante cotización y no tiene precio público fijo.

## Objetivo

Corregir el marcado de datos estructurados sin inventar precios, ofertas, valoraciones ni reseñas.

## Actividades

1. Revisar AGENTS.md y las implementaciones SEO de PYP-028 y PYP-029.
2. Localizar el JSON-LD Product de CLG.
3. Retirar el marcado Product destinado a resultados enriquecidos comerciales, manteniendo toda la información visible de CLG.
4. Conservar los datos estructurados válidos de Organization, WebPage y BreadcrumbList cuando correspondan.
5. Verificar que el nombre de producto, las características técnicas y el caso de éxito permanezcan visibles en el contenido HTML.
6. Conservar el canonical, metadatos, Open Graph, imágenes y sitemap.
7. No crear ofertas, precios, reseñas ni puntuaciones ficticias.
8. Verificar que el HTML generado no conserve otro Product duplicado.
9. Ejecutar build comercial, VitePress estricto y validaciones SEO.
10. Ejecutar git diff --check.

## Publicación

NO ejecutar git add, commit, push ni despliegue.

Este ajuste debe quedar preparado localmente para agruparlo con las siguientes mejoras SEO y publicar todo en un solo commit.
