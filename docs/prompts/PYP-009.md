## FASE 2 — AUDITORÍA GIT

Ejecutar:

- git status --short
- git diff --stat
- git diff --check
- git ls-files dist
- git ls-files docs

Identificar:

- Cambios correspondientes a las páginas web.
- Archivos nuevos que deben versionarse.
- Archivos generados que no deben incluirse.
- Documentación y evidencias que deben conservarse.
- Archivos temporales o duplicados.
- Modificaciones previas no relacionadas con Navbar.

No ejecutar git add, commit, reset, clean ni push.

- src/App.jsx

## FASE 4 — SEO Y PUBLICACIÓN
